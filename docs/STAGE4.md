## 计划调整规则

训练页会汇总当前计划里每个主要动作的负荷建议，只列出**会改变计划**的三类：

| 建议   | 触发条件                           | 落地方式                             |
| ------ | ---------------------------------- | ------------------------------------ |
| 加量   | 最近两次全部组达目标次数且难度 ≤ 7 | 哑铃 +1 kg；弹力带 +1 档；徒手 +2 次 |
| 降载   | 上次难度 ≥ 9                       | 起始负荷降至 95%                     |
| 换动作 | 任一次记录训练中不适               | 换成动作库里的替代动作并重置负荷     |

流程固定为：建议 → 「按建议生成新计划」→ 预览（显示今天的变化）→「确认使用此计划」。**确认前不写库**，旧版本归档保留。

## 图表口径

- 动作进步：只取有实际完成组的记录；同一动作至少两次才出曲线。有负荷时画最大负荷，全部为 0（徒手）时改画完成次数。容量作为数值显示在标题，不画第二根线——两者量纲差一个数量级，混在一根 Y 轴会把负荷压成直线。
- 身体变化：腰围 / 臀围始终可选，体重仅在「我的」打开显示开关后出现；关闭后即使之前选中体重也回退到腰围。
- 饮水：并入原有趋势图，作为第四个视图。

## 边界

- 计划调整只能整份重新生成，仍不支持单日单动作的手动编辑。
- 建议依赖「同一动作」的历史；训练中换过动作的记录记在新动作名下。
- 图表没有做数据下钻（点某一天看详情）。
