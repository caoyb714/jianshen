## 浏览器与环境

最终测试直接连接 `http://127.0.0.1:4174` 的生产预览，使用环境变量 `HERFIT_TEST_BASE_URL`，以避免 Windows 测试服务器自动退出卡住。默认 E2E 配置仍可自启 Vite；若本机遇到退出卡住，可先自行启动 preview，再设置此变量。

```powershell
# 窗口 1
npm run build
npm run preview -- --port 4174 --strictPort

# 窗口 2
$env:HERFIT_TEST_BASE_URL='http://127.0.0.1:4174'
npm run test:e2e
```

应用内 Browser 导航失败（缺少网络策略），系统 Edge 启动失败，因此使用项目版本匹配的 Playwright Chromium Headless Shell。续接任务后遇到网络权限未继承，已取得本轮权限并重启预览后完成验证。此前基础设施失败不计为功能通过。

构建有两条 Zod 依赖注释的 Rollup 解析提示，构建器移除相关注释后成功生成文件；未发现应用运行错误。测试运行有 NO_COLOR/FORCE_COLOR 环境提示，不影响用例结果。

## 视觉核对

已用实际截图对比 `docs/design/concept.png`：

1. 导航：桌面左侧五栏，手机底部五栏，选中态为粉色；安全区有保留。
2. 配色：奶油白主背景、粉色训练区、绿色饮水、淡紫睡眠，正文深色。
3. 字体：本地中文衬线标题、无衬线正文，字体加载实测正常；末轮提高了部分说明文字字号与对比度。
4. 插画：独立生成的瑜伽垫/哑铃/花瓶素材；真实 HTML 文本和按钮叠放，图片不是整张界面。
5. 布局：训练、周记录、生活状态、日记的顺序保留；桌面并列、手机堆叠，无横向溢出。
6. 文案与数据：概念中的静态 2/3 改为当前日期实际统计；不引入统一饮水目标；本机演示与未共享提示常驻。这些是落实产品边界的有意差异。

概念图是双屏设计板，实际浏览器分别验证桌面与手机尺寸，未将整张设计板当作网页尺寸。最终截图已另存于交付目录。
