### 本轮新增覆盖

- 动作库完整性：id 唯一、替代动作存在、五类动作模式齐全、每项都有步骤/要点/注意事项。
- 规则引擎安全边界：未确认限制拒绝生成、无器械拒绝生成、有身体限制只排入门低冲击、零基础只排入门动作、只勾徒手时不出现器械动作。
- 计划结构：同一档案两次生成结果一致、按每周天数排训练日、全身日覆盖五个动作模式、每个训练日以放松收尾、时长不超预算、一周内不重复动作。
- 渐进建议：数据不足、连续达标加量、徒手改为加次数、未达标保持、高难度降载、不适停止并给替代动作。
- 数据库：两个档案位上限与第三个被拒、逐组载荷非法值拒绝、计划唯一生效（写第二个 active 会自动归档前一个）、畸形计划拒绝。
- 浏览器：生成计划 → 确认 → 逐组打卡 → 休息计时 → 换动作 → 保存 → 记录显示「部分完成 / 已完成 / 因不适停止」、第二个档案位建立与切换、清除只影响当前档案。
