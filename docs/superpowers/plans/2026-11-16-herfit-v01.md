# HerFit v0.1 Implementation Plan

> For agentic workers: use superpowers:executing-plans to implement task-by-task. Preserve the explicitly chosen scope; no additional product approval is needed for this local first version.

**Goal:** 交付五页可体验的本机演示与可由其他 AI 接手的完整项目。

**Architecture:** React Router 页面层、Context 状态层、Zod 数据校验、本机 Repository。数据模式带版本，云端服务未来替换边界清楚。

**Tech Stack:** React, TypeScript, Vite, Tailwind, React Hook Form, Zod, Recharts, Lucide, Vitest, Playwright, vite-plugin-pwa。

**Spec:** docs/PRD.md（来自用户已选定方案）。

## Global Constraints
- 本机演示标识常驻，禁止虚构同步/审核/授权状态。
- 不设减重绩效；体重记录可关闭。
- 不连接收费 API、不上传真实健康数据。

## Review Focus
- 午夜/周日/跨月的本地日期聚合：domain tests 验证。
- localStorage 无权限或容量满：写入错误必须反馈且不伪造成功。
- 损坏/未知版本本地数据：保持原始数据并提示清空恢复。
- 训练未做任何动作/出现不适：不能记作全部完成，不鼓励继续训练。
- 手机窄屏、键盘、路由刷新、数据清空后的空状态。
