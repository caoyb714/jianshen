# 测试与验收

v0.2 新增数据库、配置和共享流程测试。使用 [阶段 2 验收命令](STAGE2.md) 跑两套 Playwright 项目。下文的 v0.1 用例仍作为演示模式回归。

## 自动化命令

| 命令             | 验证                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| npm test         | 本地日期、跨月周日、版本化读写、损坏数据保留、写入失败、空统计、不适停止分类 |
| npm run build    | TypeScript、Vite 生产编译、manifest、service worker 和静态缓存构建           |
| npm run test:e2e | 10 个用户流程 × 桌面/手机尺寸 Chromium，共 20 项                             |

E2E 内容：五页直接访问与无横向溢出；饮水刷新保留；部分训练记录；不适停止；关闭体重与清空确认；档案校验与刷新；JSON 导出；跨午夜饮水；不适停止时修正错误数值；身体限制主动确认与重新确认。

## 浏览器人工/脚本检查

视口：1440×1000、390×844、320×740。逐页检查标题、非空内容、无框架错误覆盖、无横向溢出、图像及字体加载、控制台错误。对比概念稿与真实截图，检查导航、配色、标题/正文字号、插画与文字层次、表单与卡片间距。

应用内 Browser 曾因“缺少网络策略”无法导航，改用项目 Playwright Chromium。系统 Edge 在受限环境启动失败，后使用项目版本匹配的 headless Chromium。不能把测试设施失败描述为页面测试通过；最终结果以运行成功的用例为准。

生产 PWA 检查：启动 Vite preview（dist），在独立浏览器上下文检查 manifest、图标、service worker ready/control；等待预缓存后断网重新打开首页和成长路由，确认静态资源可用。此检查不替代正式 HTTPS 的安装流程与推送测试。
