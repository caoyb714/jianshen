# 安全与隐私边界

v0.2 的共享模式已实现成员 RLS、审计字段和会话隔离。部署时按 [STAGE2.md](STAGE2.md) 关闭托管项目注册并预置成员。下文的正式验收要求仍适用。

## v0.1 已有边界

- 无账号、网络数据接口、照片上传、分析追踪、付费 AI、第三方字体请求。
- 所有示例均虚构；本机持久化未加密，不是安全健康数据仓库。设备上的其他程序/同源脚本可能读取 localStorage。
- React 文本转义；不用 dangerouslySetInnerHTML。JSON 导出通过 Blob 下载，不经第三方。
- Zod 校验读取/写入、损坏数据保留、失败提示；空白表单不会悄悄变成 0。
- 删除/重载均需确认；隐藏体重不等于删除，界面提示导出仍包含历史。
- 只缓存静态文件；CSP 响应头限制同源，服务端配置需部署后验证。

## 阶段 2 必须做

关闭公开注册，仅管理员预置两个独立账号；不能把“知道网址”当权限。用 RLS 保护每条记录，服务端设审计用户。共享空间成员身份由受控流程创建，客户端无自我加入权限。

只收集经本人同意的数据；身体限制与测量值均属敏感信息。退出清除个人内存与缓存，不缓存受保护 API 响应。不把 token/档案写入日志、构建产物、Git、错误上报。

环境变量进入 Vite 会被打进客户端，因此仅公开配置可用 VITE_ 前缀；永不放 service_role。凭证留在供应商安全界面，不在聊天、README 或 .env.example 粘贴真值。

导出要保留版本、空间与操作人信息；导入需 schema 校验、预览和覆盖确认。当前尚未提供导入/恢复按钮，不得把“可导出”宣称为完成备份恢复测试。

发布真实健康服务前完成 RLS 越权验证、权限撤销、会话过期、并发写入、网络失败、备份恢复和两台真机验收。免费额度/暂停/备份政策可能变化，部署时重新核查，不沿用聊天中的额度作为保证。
