# 训练内容与安全设计

## 当前示例

src/domain/catalog.ts 的 6 个动作、4 个模板是界面演示内容，不是经专业审核的计划，不由档案自动推荐。数据中不保存 reviewed=true 等虚假审核标记。以成人示例档案演示，不服务未成年人、孕产期或特定伤病康复。

椅子坐站、墙面俯卧撑等动作描述参考公开基础运动资料后用自己的简短文字表达，但这种参考不构成专业审核；其他动作与整套模板仍需要逐项审查。参考：[NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/)。

## 后续规则引擎（未实现）

1. 检查年龄、运动经验、时间、器械、身体限制是否齐全；限制未经主动确认则拒绝自动生成。
2. 已有伤病/限制、特殊人群或异常不适，不靠简单关键词排除替代专业评估，应停止自动推荐并要求人工确认。
3. 只选择带来源、版本、审核人与审核时间的模板；无合适动作则说明原因，不能强行填满。
4. 模板包含热身、主要训练、放松、休息和可选替代动作；按能力与器械适配，不能只依赖身高体重。
5. 连续轻松完成可以提出待确认建议，不自动加重量/组数/次数；保留之前计划版本及确认记录。
6. 疼痛、头晕或异常不适立即停止本次训练并记录，不用打卡文案鼓励坚持；严重/持续不适提示寻求医疗帮助。

当前页面已提供不适停止与反馈，但不作病因判断、医学诊断或治疗建议。正式上线前需要合适专业人员审核内容与规则。
