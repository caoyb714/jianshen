# HerFit v0.1 产品范围

来源：用户于 2026-11-16 提供的完整方案，已选择 React PWA + Supabase + Cloudflare Pages。当前交付阶段 0、阶段 1；后续 AI 接续阶段 2—5。

## 产品

供情侣两人共同管理的私人健康与运动记录系统，主要档案为女朋友。关注力量、体能、睡眠、精力与习惯；体重是自愿观察项，无减重指标。文案：照顾好身体，也照顾好自己。A little better, every day.

## 首版验收

- 首页、训练、记录、成长、我的五个导航；桌面侧栏与手机底栏。
- 首页：本周记录、示例训练安排、饮水、睡眠、精力；所有初始数值标示演示。
- 训练：示例模板筛选、动作详情、逐动作填写实际组数与次数、训练难度及不适反馈；提交后记录联动。不是个性化规则推荐。
- 记录：饮水、睡眠、精力、三餐/蛋白质/蔬果习惯、可选身体指标及训练历史。
- 成长：从真实的本地演示记录聚合近 7/28 天趋势，不硬编码成长百分比；可隐藏体重。
- 我的：档案编辑，年龄/身高/经验/活动量/目标/可用时间/器械/身体限制主动确认；本机 JSON 导出、清空、重新加载示例。
- 默认内置虚构示例；所有操作只写当前浏览器。持久化失败不可提示已保存。损坏数据不静默覆盖。
- PWA manifest 和静态缓存基础配置；正式 HTTPS 安装与真机验证属于阶段 5。

## 目前不交付

真实登录/注册、两个账号/共享空间、Supabase 同步与生产 RLS、审核过的训练规则、付费 AI、卡路里、照片上传、推送、离线云端写队列、公开部署。

## 设计

奶油白 #FFF9F7、主粉 #E8B7C5、淡紫 #D8D0ED、柔绿 #C6DCCB、深色正文 #494047；主按钮使用更深玫瑰色以保障对比度。底部导航固定且避开安全区。按钮触控区至少 44px，键盘焦点清晰。

## 范围判断

使用用户已选定的技术路线直接实现首版；不另建微信小程序。相比直接联通账号与云端，先验证 UI 可避免将未经验证的权限与训练规则误交付为成品。本机演示额外实现交互持久化，便于验收，不作为正式存储方案。
